## Run locally

This is a static website. It requires no package installation or build step. From the project folder, start a local server:

```powershell
python -m http.server 8000
```

Then open [http://localhost:8000](http://localhost:8000). If Python is installed through the Windows launcher, `py -m http.server 8000` also works.

## Deploy with GitHub Pages

1. Open the repository's **Settings → Pages**.
2. Select **Deploy from a branch** as the source.
3. Choose the `main` branch and the `/(root)` folder, then save.
4. Open the published URL shown in the Pages settings.

The site uses static HTML, CSS, and JavaScript. Google Fonts are loaded from Google Fonts; the page's font fallbacks remain available if the external service cannot be reached.
